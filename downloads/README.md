# Windows desktop preview

Download `OwnerTracker-Desktop-preview4.zip`, extract the full directory, and use the V11 Windows installation guide. Node 22.16+ within 22.x is required. Preserve .env and shop data on upgrades. The rebuilt launcher opens Shop Desktop with Sales / POS and Calendar access.

This preview contains source, the Windows x64 launcher and a verified release manifest. It contains no customer data or live credentials. Google OAuth setup and the recovered QuickBooks ZIP are still required; the historical data has not been merged. Read [shop rollout](../docs/SHOP_DESKTOP_ROLLOUT.md) before store use.
