# Windows desktop preview

Download `OwnerTracker-Desktop-preview5.zip`, extract the full directory, and use the V11 Windows installation guide. Node 22.16+ within 22.x is required. Preserve .env and shop data on upgrades. The rebuilt launcher opens Shop Desktop with Sales / POS and Calendar access.

This preview contains source, the Windows x64 launcher and a verified release manifest. It contains no customer data or live credentials. Google OAuth setup remains separate. Real customer data and private migration completion records are never bundled in this public software download. Restore only a reviewed private shop backup. Read [shop rollout](../docs/SHOP_DESKTOP_ROLLOUT.md) before store use.
